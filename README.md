# House Price Prediction

This is a beginner-level Machine Learning project that predicts house prices using a dataset of house-related information.

## Project Description

The goal of this project is to understand how Machine Learning can be used to predict house prices based on different features.

The project uses **Linear Regression** to train a model and make predictions.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Files

* `house_price.csv` — Dataset used for training and testing the model.
* `machine_practice.py` — Python file containing the Machine Learning code.
* `README.md` — Project documentation.

## Machine Learning Model

The project uses:

**Linear Regression**

The model learns the relationship between the input features and house prices and then uses that relationship to predict prices for new data.

## Main Steps

1. Load the dataset using Pandas.
2. Explore and understand the data.
3. Select the required features.
4. Split the data into training and testing sets.
5. Train the Linear Regression model.
6. Make predictions.
7. Compare the predicted values with the actual values.

## How to Run

First, make sure Python is installed on your computer.

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

Then run:

```bash
python machine_practice.py
```
